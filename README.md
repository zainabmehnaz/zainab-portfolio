# Zainab Portfolio

A responsive personal portfolio website for Zainab Mehnaz, an AI automation specialist, with a contact form, dark mode toggle, filterable services table, and add-on price calculator. Built with HTML5, CSS3, and vanilla JavaScript as a web development course assignment.

## Features

- Responsive layout that works on phone and laptop
- Light/Dark mode toggle
- Services table with hover highlighting and category filter buttons
- Add-on services checkboxes with a live total price
- Contact form with validation and a personalized thank-you message
- Age-based discount check using the birth year field
- Live character counter for the special notes box
- "Read More / Read Less" toggle in the About section
- Dynamic open/closed status based on the current time

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)

## How to Run the Project

You can view the live project directly here: [Live Demo](https://zainabmehnaz.github.io/zainab-portfolio/)

Alternatively, to run it locally:
1. Clone or download this repository.
2. Open the project folder and double-click the `index.html` file.
3. The website will open automatically in your default web browser.

Note: For the best experience, use a modern browser like Google Chrome or Mozilla Firefox.

## Project Structure

- `index.html` - page structure and content
- `styles.css` - styling, dark mode, and mobile responsiveness
- `script.js` - all interactive features
